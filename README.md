A responsive frontend warehouse management system built using HTML5, CSS3, and JavaScript as part of the Data Alcott Systems Web Development Internship.

- **Project Name:** WarehousePro
- **Task ID:** WD-LOG-003
- **Domain:** Warehouse Management

- **Internship:** Free Web Development Internship Online
- **Company:** Data Alcott Systems

## Overview

WarehousePro is a warehouse inventory management web application designed to simplify product management, stock tracking, shipment handling, warehouse location organization, and inventory reporting.

The application provides a centralized dashboard for monitoring inventory information and accessing different warehouse management modules.

## Features

### 1. Dashboard
- Inventory overview
- Stock distribution visualization
- Low-stock alerts
- Warehouse capacity overview
- Inventory statistics

### 2. Product Management
- Add new products
- Edit existing product details
- Delete products
- Search products
- Manage SKU, category, price, and stock quantity

### 3. Stock Management
- Track stock levels
- Record stock-in and stock-out transactions
- Validate available stock
- Maintain stock movement history
- Identify low-stock and out-of-stock products

### 4. Incoming Shipments
- Record received shipments
- Enter supplier details
- Track purchase order references
- Update inventory after receiving stock

### 5. Outgoing Shipments
- Create outgoing orders
- Enter customer details
- Track shipment status
- Dispatch orders and update stock quantities

### 6. Warehouse Locations
- Manage warehouse zones
- Organize aisles, racks, and bins
- Track storage capacity and utilization

### 7. Inventory Reports
- View stock reports
- Calculate inventory valuation
- Review product stock status
- Export product and stock movement data to CSV

### 8. Login and Settings
- Demo login and registration interface
- Dark mode option
- Save application preferences
- Reset demonstration data

## Getting Started

### Prerequisites
- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension (optional)

### Installation

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Ensure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` using Live Server or your browser.
5. Explore the available warehouse management modules.

## Data Storage

This project is a frontend-only demonstration. Application data is stored in browser localStorage, so saved information can persist across page refreshes in the same browser.

No backend server or database is required.

**Note:** The login and registration functionality is intended for demonstration purposes only. It is not suitable for production authentication or storing real user passwords.
